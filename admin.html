Private Content Editor

This page lets you update the website without opening folders, editing code, creating PDFs, or making slideshows.

One-time setup: the website owner must provide a GitHub publishing key. Once it is saved in this browser, use the large Publish buttons. The key is kept only in this browser and is never shown on the public website.

Private sign in

Website connection

Enter the publishing key once on this computer.

Schedule

Change dates, times, opponents, locations, results, and logos. Use End date for a multi-day event; leave it blank for a single-day event.

Roster and bios

Change a person’s information, picture, or biography. The biography is published automatically to that roster member’s bio page.

Write an article

Type an article or upload a Word document, PDF, text file, Markdown file, HTML file, or rich-text file. The editor creates the web article and adds it to the Media page automatically.

Home picture and team gear

Choose a picture from the computer. You can change the team-gear web address or turn the link off while the store is inactive.
